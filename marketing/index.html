Install

Run your browser from the keyboard.

Monocle is a command palette for Chrome and Firefox. Press ⌘⇧K on any page, type what you want — tabs, history, bookmarks, browser actions, your own automations, site commands — and hit Enter.

Three keys.

No menus to hunt through, no mouse to reach for. Open, type, run.

  1. ⌘⇧K

    Open

    The palette appears over whatever page you're on — or front and center on your new tab.

  2. a–z

    Type

    Search is instant, and results are ranked by how you actually use them. Favorites float to the top.

  3. ↵

    Run

    Enter runs the command. ⌘↵ runs its alternate action — like “open in a new tab.”

window.Monocle

Your site can join in.

Any page can register its own commands through window.Monocle — open its search, jump to a section, run a saved query — with no extension permissions and no build step.

  • Session-only. Commands live as long as the page does.
  • Non-privileged. Site commands run in the page; they can't touch browser APIs or bind global shortcuts.
  • Validated at the boundary. Strict schema, size limits, safe icons — checked before the extension sees a thing.

Read the developer reference →

page javascript
window.Monocle.commands.register({
  namespace: "docs",
  name: "Docs",
  icon: { type: "lucide", name: "BookOpen" },
  commands: [{
    id: "open-search",
    type: "action",
    name: "Open Site Search",
    placement: "root",
    onExecute() {
      document
        .querySelector("[type='search']")
        ?.focus()
    },
  }],
})
Permissions, on demand

Monocle installs with the minimum it needs. History, bookmarks, and container access are optional permissions — the palette asks the first time you use a command that needs one, and execution is re-checked in the background every time. Nothing is collected, and nothing leaves your device. Security & privacy →

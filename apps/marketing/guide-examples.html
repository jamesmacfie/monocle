Automations / Cookbook

Cookbook

Five complete automation drafts you can adapt. Copy one into the importer, then tweak the selectors and scope. The builder's Add Examples button installs a similar curated set, and Test on Active Tab lets you run any of them step-by-step to debug before you arm a trigger.

Auto-fill a dev login

A manual automation (plus a keybinding) that pulls a username and password from snippets and fills the dev login form. The credentials are resolved in the background and not logged by Monocle; the {{user}} and {{pass}} templates are expanded before the page sees them. 

{
  "schemaVersion": 1,
  "name": "Dev login",
  "icon": "LogIn",
  "color": "teal",
  "enabled": true,
  "urlRules": { "allowUrls": ["dev.example.com"] },
  "triggers": [{ "type": "manual" }],
  "vars": {
    "user": { "kind": "snippet", "snippetId": "dev-username" },
    "pass": { "kind": "snippet", "snippetId": "dev-password" }
  },
  "steps": [
    {
      "op": "fill",
      "target": { "strategy": "css", "value": "#username" },
      "text": "{{user}}"
    },
    {
      "op": "fill",
      "target": { "strategy": "css", "value": "#password" },
      "text": "{{pass}}"
    },
    {
      "op": "click",
      "target": { "strategy": "text", "value": "Sign in" }
    },
    {
      "op": "wait",
      "for": { "urlIncludes": "dashboard" },
      "timeoutMs": 5000
    },
    {
      "op": "toast",
      "level": "success",
      "message": "Logged in"
    }
  ]
}
Keybinding

Bind this script's command to a shortcut like CtrlShiftL. A non-shift modifier is required so the binding still fires while an <input> is focused.

Extract article metadata & copy

A manual automation that reads the page heading, falls back to the document title when there's no h1, formats the metadata, and copies it to the clipboard. It uses two runtime variables, a branch whose then runs getText and whose else runs setVariable, and pipes (| trim, | slice) to clean up the values. 

{
  "schemaVersion": 1,
  "name": "Copy article metadata",
  "icon": "Copy",
  "color": "blue",
  "enabled": true,
  "triggers": [{ "type": "manual" }],
  "vars": {
    "heading": { "kind": "runtime" },
    "metadata": { "kind": "runtime" }
  },
  "steps": [
    {
      "op": "branch",
      "if": {
        "kind": "elementExists",
        "selector": { "strategy": "css", "value": "h1" }
      },
      "then": [
        {
          "op": "getText",
          "from": { "strategy": "css", "value": "h1" },
          "toVar": "heading"
        }
      ],
      "else": [
        {
          "op": "setVariable",
          "name": "heading",
          "value": "{title}"
        }
      ]
    },
    {
      "op": "setVariable",
      "name": "metadata",
      "value": "**{{heading | trim}}**\n\n{url}\n\nCopied at {timestamp}"
    },
    {
      "op": "clipboardWrite",
      "text": "{{metadata}}"
    },
    {
      "op": "toast",
      "level": "success",
      "message": "Copied: {{heading | slice:0:60}}"
    }
  ]
}

Dismiss cookie banners automatically

A manual trigger plus an elementAppears trigger that fires when an "Accept all" button shows up. A branch clicks the button and confirms with a success toast when it exists, or shows an info toast otherwise — so a manual run is harmless even when no banner is present. 

{
  "schemaVersion": 1,
  "name": "Dismiss cookie banner",
  "icon": "Cookie",
  "color": "amber",
  "enabled": true,
  "triggers": [
    { "type": "manual" },
    {
      "type": "elementAppears",
      "selector": { "strategy": "text", "value": "Accept all" },
      "oncePerPage": true,
      "throttleMs": 250,
      "disarmed": false
    }
  ],
  "steps": [
    {
      "op": "branch",
      "if": {
        "kind": "elementExists",
        "selector": { "strategy": "text", "value": "Accept all" }
      },
      "then": [
        {
          "op": "click",
          "target": { "strategy": "text", "value": "Accept all" }
        },
        {
          "op": "toast",
          "level": "success",
          "message": "Cookie banner dismissed"
        }
      ],
      "else": [
        {
          "op": "toast",
          "level": "info",
          "message": "No cookie banner found"
        }
      ]
    }
  ]
}

Bulk process with forEach

A manual automation that checks every checkbox on the page by looping over them with forEach. Because the check step's selector is structurally identical to the loop's selector, it is pinned to the current match on each iteration — acting on "this checkbox" without any templating. 

{
  "schemaVersion": 1,
  "name": "Check every checkbox",
  "icon": "ListChecks",
  "color": "green",
  "enabled": true,
  "triggers": [{ "type": "manual" }],
  "steps": [
    {
      "op": "forEach",
      "over": {
        "elements": { "strategy": "css", "value": "input[type='checkbox']" }
      },
      "as": "item",
      "maxIterations": 50,
      "steps": [
        {
          "op": "check",
          "target": { "strategy": "css", "value": "input[type='checkbox']" }
        }
      ]
    },
    {
      "op": "toast",
      "level": "success",
      "message": "Visible checkboxes checked"
    }
  ]
}

Click-through pagination with while

A manual automation that clicks a "Load more" button repeatedly until it disappears. The while loop runs as long as the button exists, capped at maxIterations: 10 as a safety net, with a wait inside so the page has time to render the next batch. 

{
  "schemaVersion": 1,
  "name": "Click 'Load more' until done",
  "icon": "ArrowDownToLine",
  "color": "indigo",
  "enabled": true,
  "triggers": [{ "type": "manual" }],
  "steps": [
    {
      "op": "while",
      "condition": {
        "kind": "elementExists",
        "selector": { "strategy": "text", "value": "Load more" }
      },
      "maxIterations": 10,
      "steps": [
        {
          "op": "click",
          "target": { "strategy": "text", "value": "Load more" }
        },
        {
          "op": "wait",
          "for": { "timeMs": 1000 }
        }
      ]
    },
    {
      "op": "toast",
      "level": "info",
      "message": "Pagination loop finished"
    }
  ]
}

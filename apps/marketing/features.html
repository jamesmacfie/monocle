Features

Browser work, on the keyboard.

Monocle collects browser actions and deeper feature modules behind one search surface. Type a few letters, inspect the result, and run an eligible command without opening the browser's menus.

The command palette

The heart of Monocle. One shortcut, commands for the current context, ranked by how you use them.

Instant search

Debounced full-text matching across a command's name, keywords, description, breadcrumb, and keybinding — exact, prefix, word-boundary, substring, then fuzzy, in that order.

Usage ranking & favorites

Results are scored by frequency, recency (7-day half-life), and time-of-day habit. Star anything to pin it to the top of the empty state.

Deep search

Individual bookmarks, tabs, and history entries surface in root search without opening their group — type the title, hit Enter.

Nested pages & forms

Groups expand into child pages; forms take text, selects, toggles, and multi-value fields inline — all without touching the mouse.

Primary & alternate actions

Enter runs a command; ⌘↵ runs its alternate (e.g. open in a new tab). ⌥ opens a per-command action menu.

Custom keybindings

Bind eligible, stable commands to a shortcut or a multi-stroke sequence (g g), with conflict detection. Confirm-gated and many dynamic rows are deliberately excluded.

Built-in commands

A representative catalog of what is in the palette out of the box. Rows are searchable; custom keybindings are available only where the command has a stable id and allows them.

Feature modules

Beyond commands, Monocle bundles a few deeper features — each with its own settings page and page UI, all rendered through the same declarative surface system.

Focus Mode

Block distracting sites while you work. Maintain a URL blocklist, then start an indefinite, timed (30 / 60 minute), or Pomodoro session. Blocked pages get a full-screen hard-block overlay you can't click past, and your new tab shows a live countdown badge. Session timing is timestamp-based with a single end alarm — no per-second background work.

  • Start Focus
  • Start for 30 / 60 Minutes
  • Start Pomodoro
  • Stop Focus
  • Configure Focus Mode

Tab Groups

Save the current window's tabs as a named collection — preserving each tab's pinned state, muted audio, and (on Firefox) its container — and restore the whole set later. On Chrome, a second set of commands drives native tab groups: add to group, group the window, rename, recolor, collapse, and ungroup.

  • Save Tabs as Group
  • Restore Tab Group
  • Add Tab to Group (Chrome)
  • Rename / Recolor / Collapse (Chrome)

Element Hider

“Hide element on this page” puts the page into pick-mode — hover to highlight, click to hide. Monocle generates a stable selector, saves a best-effort per-domain selector, and hides the element immediately. A separate read-only automation reapplies each rule on future loads, so one failed selector does not stop the remaining hide rules. Site changes can still make a selector fail or match the wrong element; remove stale rules from Manage hidden elements.

  • Hide element on this page
  • Manage hidden elements

Inline calculations

Start typing math, a unit conversion, or a time-zone lookup and the answer appears right above your search results. Enter copies it and keeps the palette open. Three providers cover it:

  • Math — 1 + 89, sqrt(16), 2 * 3
  • Units — 1 mile in km, 5 kg to lb, 5'10" in cm, 6 stone 4 lb
  • Time — time in Auckland, time in New York

Powered by a hardened mathjs (injection functions disabled, in the background only) and Intl.DateTimeFormat. Results are ephemeral — never stored, never ranked.

Snippets

Save reusable text and insert it at your caret on any page. Bodies support placeholders resolved at insert time — and snippets can carry their own custom shortcut (a modifier is required so it fires while you're typing in a field).

  • {date:FORMAT} — any date-fns format, plus {date} / {time} / {datetime}
  • {url} · {title} · {domain} · {path}
  • {uuid} · {timestamp} · {i} (a persisted counter)

Commands that know where you are

Built-in contextual commands appear only on the sites they belong to. GitHub is the current prototype and uses URL-aware navigation plus best-effort page actions.

Go to & Search

Jump to Code, Issues, Pull Requests, Actions, Releases, Branches, Commits, Wiki, Discussions, Insights, Security, or Settings — plus in-page and global code search.

My GitHub & Create

Your open PRs, PRs awaiting review, assigned issues, and notifications; quick-create a new issue, PR, release, or discussion.

PR & issue navigation

On a pull request: Conversation, Commits, Checks, Files Changed, and back to Code. On an issue: Conversation and Code.

Toggle Star

Attempt to star or unstar the current repository through GitHub's current page controls. Visibility is driven by URL rules, and the action can need maintenance when GitHub changes its DOM.
